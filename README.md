# Sky

**Sky — Study Intelligence.**

Sky is a personal learning platform designed to help students organize knowledge, understand their progress, identify knowledge gaps, and prepare more effectively for exams.

The project aims to combine structured learning materials, knowledge assessment, revision planning, and optional AI-assisted learning into one coherent environment.

## Project status

Currently in early development.

The initial target is a Windows desktop application, followed by a mobile application and a centralized backend for cross-device synchronization.

## Architecture

The planned technology stack:

- **Frontend:** React, TypeScript
- **Desktop:** Tauri 2
- **Backend:** ASP.NET Core
- **Database:** PostgreSQL
- **Version control:** Git and GitHub

The backend is designed as a modular monolith with a REST API.

## Repository structure

- `apps/` — client applications
- `backend/` — server-side solution
- `shared/` — reusable components and contracts
- `docs/` — technical documentation
- `scripts/` — development and maintenance scripts
